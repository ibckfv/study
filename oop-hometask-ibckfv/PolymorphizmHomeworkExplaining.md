\*\*Объяснение к домашней работе по полиморфизму\*\*

\*\*1. Статический ad-hoc полиморфизм:\*\*

\*\*

`  `В классе UpperWorld создан метод GetResourceUsage, который принимает на вход int и string, в зависимости от типа входного параметра выполняет разные алгоритмы.

\*\*2. Динамический ad-hoc полиморфизм:\*\*

\*\*

`  `Метод абстрактного класса MinecraftUniverse - GetDangerLevel переопределён для каждого класса-наследника по разному. В классе Program в домашнем задании на этапе компиляции не известен класс, который его вызовет, он определяется в рантайме и в зависимости от него метод переходит к одной из его вариаций.

\*\*3. Полиморфизм подтипов:\*\*

\*\*

`  `У класса MinecraftUniverse есть метод CalculateArea, который ожидает объект этого класса, но может работать с классами наследниками MinecraftUniverse.

В классе ExtensionMethod реализован метод расширения класса MinecraftUniverse, который позволяет сменить биом, в котором находится персонаж(перемещаться между локациями).
